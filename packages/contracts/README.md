# @sampledge/contracts (mirror)

Shared contracts between SUPPLY360, SAMPLEON, PROJEXA and ZAPX: the Audience Request, the event
envelope and catalogue, targeting criteria and the service request signature.

**This is a copy.** The source of truth is `packages/contracts` in
[kunalsharma-ai/Sampleon](https://github.com/kunalsharma-ai/Sampleon). Change it there first, then
copy `src/` here unchanged and keep `version` in `package.json` equal to SAMPLEON's.
See SAMPLEON's `docs/ECOSYSTEM_ARCHITECTURE.md` and, for this repository, `docs/integrations/SAMPLEON.md`.
