# Implementation status: Phase 1 + Phase 2

Legend: **Functional** = real logic running on application state · **Simulated** = fictional demo data or a stand-in for a future service, labelled in the UI · **Planned** = not built.

Nothing in this prototype is connected to a live system. No real clients, suppliers, panelists or health data are used. Panel brand names are Sampledge's; their metrics are simulated.

## Known limitations
- Single-user, browser-local state; two browsers will not see each other's changes.
- Role enforcement is UI-only until Phase 3.
- The 3D globe needs WebGL; without it the 2D map is shown automatically.
- ECharts and three.js chunks are large; they are lazy-loaded but the first visit to a 3D page downloads ~1 MB of JS.
- Logo is a placeholder wordmark because no official asset was provided.
